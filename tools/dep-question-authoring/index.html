はじめて使う方へ — Quick Start
  1. 左の一覧から既存 group を選択します（検索は任意です）。
  2. 問題・選択肢・followUp を Comparison で比較します。
  3. Selection Inspector で出題条件を試します。
  4. 必要な場合だけ Create / Add / Remove / Rename で編集します。
  5. Validation が PASS したら questions.json を Export します。

検索は任意です。空欄では全 Variant groups を表示し、Question ID・問題本文・Group 名で絞り込みます。
