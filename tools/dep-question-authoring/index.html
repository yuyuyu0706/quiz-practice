はじめて使う方へ — Quick Start
  1. 必要なら CREATE VARIANT GROUP で新しいgroupを作ります。
  2. MEMBER COMPARISON & EDIT で問題を比較・編集します。
  3. SELECTION INSPECTOR で出題条件を試します。
  4. Validation がPASSしたら Export questions.json で出力します。
  5. 出力したquestions.jsonを quiz-practice/dep-quiz-app/questions.jsonへ反映します。差分を確認して開発branchへcommitし、通常のPR / mergeフローでmainへ反映してください。

既存Variant Groupの確認だけなら、Createを飛ばしてComparisonから開始できます。

用語解説
Variant Group
同じ知識・判断基準を異なる問い方で確認する問題のまとまり。新規sessionでは、同じVariant Groupから最大1問を代表として採用します。
followUp
元問題の解説後に、理解をもう一段確認するための追加確認候補。元問題から別questionへの1段の参照であり、自動遷移そのものを意味しません。
エラー対策

同じchoice text multisetではない

Variant Groupは「同じ論点」というだけでは作成できません。group内の問題は、選択肢本文の集合が同じである必要があります。

例えばDEP-Q208とDEP-Q226はどちらもストリーミング重複排除を扱いますが、選択肢本文のセットが異なるため同じVariant Groupにはできません。

対策

  1. 単にtopic / keywordが似ている場合はgroup化しない。
  2. topic上の関連付けには既存tagsを利用する。
  3. Variantとして扱いたい場合は、同じchoice text setを使用した別の問い方として作問する。
  4. label A/B/C/Dの割り当て順は異なってよいが、choice本文そのものは一致させる。

既存問題の選択肢をValidationを通す目的だけで無理に書き換えないでください。
